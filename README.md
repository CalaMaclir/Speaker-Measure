# Speaker Measure Pro 3.3

iPhone Safariから接続中のスピーカーへ測定信号を送り、iPhone内蔵マイクで録音して解析する、依存ライブラリなしの静的Webアプリです。Bluetooth、USBオーディオ、変換アダプター経由など、iPhoneの音声出力先として利用できるスピーカーを対象にします。

## 3.0以降の測定方式

出力信号は次の順序です。

1. 0.7秒の無音
2. 開始同期マーカー（非対称2段ログチャープ）
3. 0.52秒の間隔
4. 指数サインスイープ（ESS）
5. 2.2秒の残響収録区間
6. 終了同期マーカー
7. 0.55秒の後置無音

開始マーカーは録音信号との正規化相互相関で検出します。開始位置から音声出力経路、HTML Audio再生開始、音響伝搬を含む総遅延を求め、スイープ解析区間を補正します。

終了マーカーも検出できた場合は、開始・終了マーカー間の実測サンプル数と既知の信号長を比較し、再生側と録音側のクロック差をppm単位で推定します。その時間倍率をスイープ参照信号へ反映します。

周波数特性は単純な録音FFTではなく、送信スイープを基準とした正則化付き周波数領域デコンボリューションからインパルス応答を求め、選択した時間窓を適用した後に再度FFTして算出します。

## 機能

- 20 Hz～20 kHzの指数サインスイープ
- 開始マーカーによる音声出力経路の遅延の自動補正
- 終了マーカーによるクロック差推定
- 正則化付きデコンボリューション
- 相対周波数特性
- なし／1/24／1/12／1/6／1/3オクターブ平滑化
- ラップ位相表示（直接音遅延を除去）
- インパルス応答およびETC表示
- 全残響／20～500msの時間窓
- ログスイープ追従方式による参考THD
- マイク校正CSVの読込
- 保存測定との差分表示
- 複数測定の重ね合わせ
- IndexedDBへの端末内保存
- 表示中グラフの高解像度PNG保存（iPhoneでは共有シート対応）
- 解析CSV、JSON、録音WAV出力
- 入力S/N、ピーク、クリッピング、同期品質の表示
- 測定・解析進捗とマイク入力レベルを明確に分離した表示
- マイク入力のRMS／Peak値をdBFSでリアルタイム表示
- PWAキャッシュ

## 2本のバー表示

- 上のバー「測定・解析の進行状況」：録音、再生、同期検出、デコンボリューションなど、処理全体の進捗を示します。音量ではありません。
- 下のバー「マイク入力レベル」：iPhoneのマイクが実際に受けた音の大きさをリアルタイム表示します。RMSとPeakをdBFSで併記し、黄色から赤の領域は入力過大の目安です。

## 配置

マイクAPIはHTTPSが必要です。このフォルダーの内容をGitHub Pages、Cloudflare Pages、Netlify等へそのまま配置してください。

同じURLへ旧版を上書きした場合、iPhone Safariに旧Service Workerが残ることがあります。別ディレクトリへ配置するか、URL末尾に `?v=3.3.0` を付け、タブを閉じて開き直してください。

## 推奨手順

1. iPhoneを測定対象のスピーカーへ接続する。
2. SafariでHTTPS URLを開く。
3. 「テスト音」でスピーカーからの出力を確認する。
4. 「マイクを準備」を押して許可する。
5. マイク準備後にもう一度「テスト音」を確認する。
6. 「マーカー確認」で短い2段チャープを確認する。
7. iPhoneとスピーカーを固定する。
8. 低い出力レベルから本測定を行う。
9. クリッピングが0%で、開始マーカー相関が十分高いことを確認する。

## グラフ画像の保存

解析結果の「グラフ画像」を押すと、現在表示している周波数特性、位相、ETC、参考THDのいずれかをPNG画像にします。重ね合わせ、差分基準、表示レンジも画像へ反映されます。

- iPhone／iPad：共有シートが開くため、「画像を保存」または「ファイルに保存」を選択します。
- PC：PNGファイルとしてダウンロードします。
- 出力画像：2000×1440ピクセル。タイトル、測定日時、距離、スピーカー種別、凡例を含みます。

## バスレフを10cmで測る場合

10cmは比較測定には有効ですが、ドライバーとポートの音圧比および位相差は測定位置で変わります。低域全体を厳密に評価する場合は、ドライバー近傍とポート近傍を個別測定し、放射面積と距離を考慮して合成する方法が適切です。

低域評価時は時間窓を「全残響」または500msにしてください。20ms窓では周波数分解能が約50Hz程度となり、それ以下の低域評価には適しません。

## 校正CSV

周波数と補正値dBの2列を読み込みます。カンマ、セミコロン、タブ、空白区切りに対応します。

```text
20, 3.2
25, 2.8
31.5, 2.1
1000, 0.0
10000, -1.3
20000, -3.0
```

## 制約

- 絶対SPLは測定しません。
- 結果には使用した音声出力経路、D/A変換、アンプ、スピーカー、エンクロージャー、室内、iPhoneマイクの特性が含まれます。
- iOSがエコーキャンセル、ノイズ抑制、AGCを要求どおり無効化しない場合があります。実際の状態を画面に表示します。
- 参考THDは規格準拠の測定ではありません。
- iPhone Safari実機では端末世代やiOSバージョンにより解析時間が異なります。10秒スイープでは解析に数秒～数十秒かかる場合があります。
