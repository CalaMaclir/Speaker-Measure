# Speaker Measure Pro 4.0

iPhone / iPad / PCのWebブラウザで、スピーカーへ測定信号を出力し、マイク入力から音響特性を解析するローカル完結型Webアプリです。

## 4.0.1の画面・表示修正

- iPhoneの縦画面・横画面でページ全体が横にはみ出さないように調整しました。
- 周波数特性グラフでは−36 dB以下の測定線を描画しません。値自体は解析結果とCSVに保持されます。
- PNGグラフ保存にも同じ表示下限を適用します。


## 4.0で刷新した点

### 20 kHz端点の異常ピーク対策

3.xでは、表示終了周波数とESSスイープの終了周波数が同じだったため、次の影響が20 kHz付近に現れる場合がありました。

- スイープ終端のフェード
- 逆フィルタの端部増幅
- 録音・再生クロック差
- 終了マーカーの近接
- FFT端部の信頼性低下

4.0では、表示帯域の外側まで励振する**ガード帯域付きESS**へ変更しました。

48 kHz入力で表示範囲が20 Hz～20 kHzの場合、内部では概ね次の帯域を励振します。

```text
内部励振：約15.4 Hz ～ 21.84 kHz
表示帯域：20 Hz ～ 20 kHz
```

周波数特性の振幅は、逆フィルタ端部のFFT値ではなく、ESS位相へ同期した**コヒーレント・スイープ追従解析**で算出します。デコンボリューションは位相、群遅延、インパルス応答、時間減衰の算出に使用します。

44.1 kHz入力では20 kHzより上に十分なガード帯域を確保できないため、信頼上限を約18.9 kHzとして、それ以上を自動的に非表示にします。

### マーカーの完全分離

測定信号は次の順序です。

```text
無音
→ Barker符号化開始マーカー
→ 0.75秒無音
→ ガード帯域付きログスイープ
→ 2.2秒残響収録
→ 0.55秒無音ガード
→ Barker符号化終了マーカー
→ 無音
```

開始・終了マーカーは7チップのBarker符号を使ったチャープ列です。開始マーカーは主に約720 Hz～3.2 kHz、終了マーカーは約4.05 kHz～8.25 kHzを使用し、20 kHz近傍へマーカー成分を置きません。

終了マーカーは解析区間から少なくとも無音ガード分だけ離しています。アプリは解析区間内に終了マーカーに似た成分がないか再検査し、「マーカー混入スコア」として表示します。

### クロック差補正

開始・終了マーカーの実測間隔から、再生側と録音側のクロック差をppm単位で推定します。録音波形はLanczos補間で時間軸補正し、位相・インパルス応答解析へ渡します。

振幅特性は推定されたクロック倍率を直接用いたESS追従解析で算出するため、高域の時間軸誤差による逆フィルタの暴れを抑えます。

### 低漏洩IR窓

選択できる窓関数：

- Blackman-Harris 4-term（初期値）
- Hann
- Tukey / cosine edge

直接音より前は短い立ち上がり窓、解析区間末尾には長い片側減衰窓を適用します。直接音を窓の端へ置いたまま全区間Blackman-Harris窓を掛ける方式ではありません。

## 配置方法

マイクAPIにはHTTPSが必要です。GitHub Pages、Cloudflare Pages、NetlifyなどのHTTPS静的ホスティングへ、このフォルダーの中身を配置してください。

旧版と同じ場所へ上書きした場合は、Safariの古いタブを閉じ、次のようにバージョンを付けて開いてください。

```text
https://設置先URL/?v=4.0.1
```

Service Workerのキャッシュ名は`Speaker Measure Pro 4.0.1`用に更新されています。

## 測定手順

1. スピーカーを接続する
2. 「テスト音」で出力先を確認する
3. 「マイクを準備」を押す
4. マイク準備後にもテスト音が同じスピーカーから出ることを確認する
5. 「マーカー確認」で符号化マーカーが聞こえることを確認する
6. マイクとスピーカーを固定する
7. 出力レベルを低めから始めて本測定する
8. 測定後に次を確認する
   - クリッピング 0%
   - 開始・終了マーカー相関
   - マーカー混入スコア
   - 解析区間余白
   - 信頼帯域

入力ピークは概ね−12～−3 dBFSを目安にしてください。

## 10 cmでバスレフスピーカーを測る場合

10 cm測定は、試作変更前後の比較や中高域の近接測定に適しています。ただし、ウーファーとポートからマイクまでの距離差により、低域の合成特性は位置で変化します。

ポート同調を詳しく確認する場合は、次の測定を分けて行う方が適切です。

- ウーファー振動板から1～2 cmの近接測定
- ポート開口から1～2 cmの近接測定
- 面積、距離、位相を考慮した合成

## 校正CSV

次の形式を読み込めます。

```csv
frequency_hz,correction_db
20,4.2
31.5,2.7
1000,0.0
10000,-1.4
20000,-3.0
```

周波数は昇順でなくても読み込み時に並べ替えます。

## 測定値の位置付け

結果には次の特性が含まれます。

```text
音声出力経路
+ D/A変換・アンプ
+ スピーカー・エンクロージャー
+ 室内音響
+ マイク・A/D変換
+ ブラウザの入力処理
```

校正されていない内蔵マイクでは、絶対SPLや規格準拠THDではなく、同一条件での相対比較を主用途としてください。

## 検証

DSPコアについて、以下の合成データ試験を行っています。

- 48 kHz、20 Hz～20 kHz、遅延ありの直結特性
- 高域・低域フィルターと反射を含む疑似スピーカー
- 約350 ppmの再生・録音クロック差
- 開始・終了マーカー検出
- 終了マーカーの解析区間外分離
- 20 kHz端点の異常な上昇が発生しないこと
- 44.1 kHz時の信頼上限自動制限

実際のiPhone、iOS、スピーカー、マイクの組み合わせによる動作は環境依存です。
