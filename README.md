# Speaker Measure Pro 4.1.0

ブラウザ上でスピーカーのESS測定・解析を行うローカルWebアプリです。4.1.0では、測定条件と解析結果をまとめたPDF測定レポートを追加しました。

## PDFレポート

測定完了後、「解析結果」欄の **PDFレポート** を押します。

出力はA4横・全8ページです。

1. 測定条件・解析概要・品質判定・警告
2. 周波数特性
3. 位相
4. 群遅延
5. インパルス / ETC
6. ステップ応答
7. 時間周波数減衰
8. THD / 高調波

周波数特性の差分基準や、チェックした保存測定の重ね表示も、PDF作成時の画面設定に従ってグラフへ反映されます。グラフの周波数範囲は、現在の入力欄ではなく、測定時に保存された開始・終了周波数を使用します。

iPhoneでPDFファイル共有に対応している場合は共有シートを開きます。対応していない環境ではPDFファイルをダウンロードします。

## PDFの実装方式

外部サービスや外部PDFライブラリへデータを送信しません。各レポートページをブラウザのCanvasで高解像度レンダリングし、`pdf-report.js`がJPEGページをA4横PDFへ格納します。

この方式により日本語フォントファイルの追加なしで表示できます。一方、PDF内の文字とグラフは画像であるため、文字検索やテキスト選択には対応しません。

## 配置ファイル

以下を同じディレクトリへ配置してください。

- `index.html`
- `styles.css`
- `app.js`
- `pdf-report.js`
- `dsp-core.js`
- `analyzer-worker.js`
- `recorder-worklet.js`
- `sw.js`
- `manifest.webmanifest`

HTTPS環境で使用してください。
